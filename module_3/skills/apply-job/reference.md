# Write a job application
Follow these steps to write a convincing text why the user is suitable for the job.

**Step 1: Introduction**: Introduce the user, his profession and current position.

**Step 2: Motivation**: Explain the motivation behind the user applying for this job.

**Step 3: Conviction**: Write something about the user that tries to convince the employer that the user can help in the job.

**Step 4: Finalize**: Conclude the sales pitch with something positive about the user.
